## 💡 Como executar

1. Clone o repositório:
   ```bash
   git clone https://github.com/carolferreira-dev/treinamento-codetroopers.git
   ```

2. Entre na pasta desejada:
   ```bash
   cd treinamento-codetroopers/busca_binaria
   ```

3. Compile o código:
   ```bash
   g++ 1025_onde_esta_o_marmore.cpp -o executavel
   ```

4. Execute o programa:
   ```bash
   ./executavel        # Linux/Mac
   executavel.exe      # Windows
   ```
